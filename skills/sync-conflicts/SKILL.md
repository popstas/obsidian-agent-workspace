Слияние модель делает верно и без инструкций. Скилл нужен для трёх вещей: охватить все вольты, а не только текущий; сохранить копии до удаления; собрать всё одним вызовом.

## 1. Сканирование

```bash
bash <папка этого скилла>/scan.sh [all] --backup <скратчпад>/sync-conflicts-backup
```

- без аргумента — вольт текущей папки;
- `all` — каждый `vault` из `~/.claude/vaults-config.md`. Берётся, если пользователь пишет «везде», «все вольты» или упоминает, что включилось старое устройство.

Скрипт ничего не удаляет. Он копирует конфликтные файлы в бэкап и по каждой копии печатает вердикт и `diff -u` (`-` — оригинал, `+` — копия).

## 2. Решение по каждой копии

| Вердикт / признак | Действие |
|---|---|
| `IDENTICAL`, `DUPLICATE` | удалить |
| `kind: obsidian-ui-state` | удалить, не сливать |
| `DIFFERS`, все `+`-строки копии уже есть в оригинале (переставлены, отмечены) или удалены позже намеренно (`git log -S '<строка>'` — коммит после даты копии; задача могла уйти ниже по лестнице в бэклог) | удалить |
| `DIFFERS`, в копии есть новая правка: закрытая задача, новый подпункт, новый текст | перенести правку в оригинал (подпункт — под тот же родитель, порядок оригинала сохранить), затем удалить копию |
| одна и та же строка изменена по-разному в оригинале и в копии | не трогать, спросить пользователя: варианты «оригинал / копия / объединить» |
| `ORIGINAL MISSING` | спросить: восстановить из копии или удалить |

Закрытую в копии задачу оформлять по правилам вольта для выполненных задач.
